# Megalodon Eco Farms 🌿

Megalodon Eco Farms is a premium e-commerce platform dedicated to 100% natural and biodegradable products made from Areca palm leaves and fresh coconuts. Our mission is to provide sustainable, chemical-free alternatives to plastic disposables.

## ✨ Features

- **Eco-Friendly Products**: Hand-crafted from fallen Areca leaves—no trees are harmed.
- **Premium Design**: Clean, modern, and responsive UI built with Vanilla HTML, CSS, and JS.
- **Dynamic Shopping Experience**: Category filtering, search functionality, and a seamless cart system.
- **Secure Payment Integration**: Supports popular Bangladeshi payment gateways like bKash and Nagad.
- **SEO Optimized**: Built with SEO best practices to ensure maximum visibility.

## 🚀 Deployment

The project is live at: [https://megalodon-eco-farms.vercel.app/](https://megalodon-eco-farms.vercel.app/)

## 🛠️ Technology Stack

- **HTML5**: Semantic structure.
- **CSS3**: Custom variables, grid/flexbox layouts, and premium animations.
- **JavaScript**: Vanilla JS for dynamic product rendering and cart logic.
